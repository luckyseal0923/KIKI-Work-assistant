# KIKI 用量與模型費用

2026-11-07：維持 `gpt-6-luna`，本版優先縮小來源與減少 API 呼叫，沒有更換模型。

## 如何減少用量

| 要求 | API 呼叫上限 | 來源方式 |
| --- | --- | --- |
| 幫助、狀態、工作清單、提案確認／取消、工作歷程、重置對話 | 0 | 固定程式與資料庫 |
| 明確追問「再短一點」「那乙呢」「是由誰負責」「期限呢」 | 1 | 有效的前次答案與精選來源 |
| 有效前次單筆工作的「這件事完成了」 | 1 | 只產生變更提案，確認仍為 0 次 |
| 「再找更早的」 | 1 | 沿用可信條件，另查更早的少量來源 |
| 一般自由問答／草擬／歷史查找／新工作提案 | 最多 2 | 先分類，再回答或提出工作提案 |
| 今日摘要／今日待辦快捷指令 | 1 | 本群今日精選文字 |

若沒有相符來源、缺上下文或需澄清，可少於表中次數；失敗不自動重試。一般知識提問不附群組歷史。提案、查詢及摘要共用原有每日 20 次 AI 要求、至少 30 秒間隔；這是接受要求的次數上限，即使要求最後不呼叫模型也可能占額度。零 AI 固定控制不占此 AI 額度。

來源預設限 20 則／筆、12,000 字元，不因群組累積數月而自動擴大。工作提案的既有紀錄與原始討論共用預算。短期上下文只送有限起始交辦、最近要求、前次成功回覆與經核對的精選來源，不重送八輪全部文字；過期不重送。固定提示、本次要求和有限的前一答仍另占 tokens，所以 12,000 字元不是總 token 上限。

## 牌價與估算

官方 [GPT-6 Luna 模型說明](https://developers.openai.com/api/docs/models/gpt-6-luna) 與 [API 價格表](https://developers.openai.com/api/docs/pricing)，核對日期 2026-11-07：標準輸入每百萬 tokens US$0.10，輸出 US$0.50。快取輸入另有牌價；程式以標準未快取費率估算，沒有假定快取必定命中。

既有合成角色測試一筆 API 合計輸入 1,764、輸出 285 tokens，以此單價估算 US$0.0003189；一千次相同用量約 US$0.3189。這是該筆的算例，不是保證未來每次費用；新功能的分類、提案及長文用量不同。

啟用 005 後，每份完成工作記錄模型、嘗試呼叫次數及 API 回報的輸入／輸出合計。「狀態」顯示今日、本月可計價用量與估算金額。舊紀錄未記模型、API 失敗／輸出無法驗證等缺完整資料者，標為未能計價，不當成免費或零成本；供應商仍可能收費。

估算非帳單，不含稅、匯率、區域差價或完整快取折扣，也不是硬性美元預算。實際支出須以 OpenAI 專案用量／帳單核對。保留原每日次數上限，本版未自行設定新的帳務額度。
